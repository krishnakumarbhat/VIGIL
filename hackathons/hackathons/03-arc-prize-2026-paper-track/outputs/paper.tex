\begin{abstract}
We present a neuro-symbolic DSL synthesis approach for ARC-AGI-2 that combines a structural primitive language (`dsl_primitives`), a D4+colour canonicalisation (`canonical`), and bidirectional depth-2 search (`search`). Real empirical results are drawn exclusively from verified sibling-track artifacts (`04-arc-prize-2026-arc-agi-2/`). On the v2 training split (`eval_metrics_training_v2.json`, 150 tasks) we observe graded pass@1 = 8.67\% (13/150) and pass@2 = 8.67\% (13/150); on the 120-task evaluation split (`eval_metrics_evaluation.json`) graded pass@1 = 0/120 (0.0\%). The corresponding Kaggle submission, made 2026-10-31, scored 0.00 on the public leaderboard (rank 3552/3554 when checked). Symbolic families (depth-1/2) achieve 97.1\% and 92.3\% precision but cover very few fits; learned families (`cell_tree`, `object_tree`, `patch_lookup`, `mlp`) supply most of the v2 training fits (41/150) via the learned ranker (`program_ranker.py`). The canonicalisation collapses equivalent states under the invariance group $G = D_4 \times B$ (order $8 \cdot k!$), shrinking the search frontier by up to 48--960$\times$ for grids using 3--5 colours. We state the orbit-stabilizer argument, the soundness conditions, and the completeness limitation for depth-$>2$ compositions. Offline split metrics were produced or read on 2026-10-22; the leaderboard result was read on 2026-10-31.
\end{abstract}

\section{Method}

\subsection{Canonicalisation and the Invariance Group}

Let $\mathcal{G}$ be the set of $30 \times 30$ integer grids with values $\{0,\dots,9\}$. The symmetry group is $G = D_4 \times B$, where $D_4$ (order 8) acts by rotation and reflection, and $B \le S_{10}$ (order $k!$) acts by colour relabelling. The canonical key is
\[
\kappa(g) = \min_{r \in D_4} \mathrm{bytes}\bigl(\mathrm{canon}(r(g))\bigr),
\]
where $\mathrm{canon}$ relabels colours by first appearance in row-major order (`canonical_colors`). The orbit size is $|\mathrm{Orbit}(g)| = |G| / |\mathrm{Stab}(g)|$; for asymmetric grids using all 10 colours this reaches $8 \cdot 10! \approx 2.9 \times 10^7$.

\subsection{DSL Operator Schema}

Every primitive is $f: \mathcal{G} \to \mathcal{G} \cup \{\bot\}$. The schema is first-order: $(\mathrm{Grid}, \mathrm{context}) \to \mathrm{Optional}[\mathrm{Grid}]$, with context including training pairs for data-dependent selection. The full operator table is given in the appendix (derived from `dsl_primitives.py`, lines 356--596).

\subsection{Bidirectional Induction Rule}

Given training pair $(s,d)$, construct forward set $F = \{\kappa(f(s)) \mid f \in \mathcal{P}\}$ and backward set $B = \{\kappa(b(d)) \mid b \in \mathcal{P}^{-1}\}$. A meeting key $k \in F \cap B$ induces program $b \circ f$, verified on all pairs (`fits_all`). Complexity is $O(|P_{\mathrm{fwd}}| + |P_{\mathrm{inv}}| + |F \cap B| \cdot |\mathrm{train}|)$, bounded to $O(10^4)$ per task by `depth1_budget = 400` and `depth1_budget = 220` for bidirectional sets.

\subsection{Depth-2 Beam Enumeration}

Ordered pairs $\mathrm{right}(\mathrm{left}(x))$ with $\mathrm{left}$ drawn from structural + data-dependent operators (excluding single colour swaps) and $\mathrm{right}$ from the fast structural + colour-swap set (`primitive_fast_set`). Pair-0 exactness filter (`src0` vs `dst0`) provides $O(1)$ screening before full verification.

\section{Limitations}

(1) Depth bound (`max_depth=2`) excludes multi-step compositions. (2) Canonicalisation complete for depth-1 / bidirectional depth-2 but incomplete for arbitrary-depth compositions with diverging intermediate symmetries. (3) Learned rules (`cell_tree`, `object_tree`) overfit few pairs (precision $<10$\%). (4) Graded pass@1 = 0\% on evaluation (`eval_metrics.json`) confirms that training fit is necessary but not sufficient.

\section{Conclusion}

The DSL + canonicalisation framework provides a sound, verifiable search space reduction under $G = D_4 \times B$, with bidirectional depth-2 induction. Real results confirm the expected ARC-AGI-2 regime: low symbolic coverage, high learned-family coverage, and zero graded evaluation generalisation despite 16.7\% training-fit rate.
